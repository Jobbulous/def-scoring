# ใบให้คะแนนโครงการ กองทุนดีอี

เว็บแอปสำหรับให้คะแนนข้อเสนอโครงการกองทุนพัฒนาดิจิทัลเพื่อเศรษฐกิจและสังคม ม.26(1) และ 26(2) ตามเกณฑ์ย่อยและขั้นคะแนนในไฟล์ `เกณฑ์พิจารณาโครงการ_รายละเอียดการให้คะแนน.xlsx`

ทั้งแอปอยู่ในไฟล์ `index.html` ไฟล์เดียว ไม่ต้องติดตั้งหรือ build อะไรเพิ่ม

## วิธีเผยแพร่ด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub เช่น `defund-scoring`
2. อัปโหลด `index.html` และ `README.md` ไว้ที่ root ของ repo (Add file → Upload files → Commit)
3. ไปที่ Settings → Pages → Source เลือก **Deploy from a branch** → Branch `main` / `(root)` → Save
4. รอ 1–2 นาที แล้วเปิดลิงก์ `https://<ชื่อผู้ใช้>.github.io/defund-scoring/`

หรือใช้คำสั่ง

```bash
git init
git add index.html README.md
git commit -m "ใบให้คะแนนโครงการ"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/defund-scoring.git
git push -u origin main
```

## การเก็บข้อมูลในเวอร์ชันนี้

- คะแนนเก็บไว้ใน **เบราว์เซอร์ของผู้ประเมินแต่ละคน** (localStorage) ไม่ได้ส่งขึ้นเซิร์ฟเวอร์
- ถ้าล้างข้อมูลเบราว์เซอร์ เปิดโหมดไม่ระบุตัวตน หรือเปลี่ยนเครื่อง คะแนนจะไม่ตามไปด้วย ให้กด **ดาวน์โหลด CSV** เก็บไว้ทุกครั้งที่ให้คะแนนเสร็จ
- แท็บ "เทียบผู้ประเมิน" จะเห็นเฉพาะคะแนนของตัวเอง ให้แต่ละคนส่งไฟล์ CSV มารวมใน Excel
- อย่า commit ไฟล์ CSV ที่มีคะแนนจริงขึ้น repo สาธารณะ

## แก้เกณฑ์

ข้อมูลเกณฑ์อยู่ในแท็ก `<script type="application/json" id="criteria">` ใน `index.html` แต่ละเกณฑ์ย่อยมี

- `max` คะแนนเต็ม และ `plus: true` สำหรับข้อ ๒.๒ ก ข ค ที่ได้ +1 เมื่อยังไม่ใช้ข้อ ๒.๒ง
- `ladder.levels` ขั้นคะแนน `{ "v": คะแนน, "t": "คำอธิบาย" }` ตามคอลัมน์ F
- `ladder262` ขั้นคะแนนเฉพาะ 26(2) ตามคอลัมน์ G (ถ้ามี)

ถ้าแก้ไฟล์ Excel แล้วอยากได้ข้อมูลชุดใหม่ ให้สร้าง JSON ใหม่จากไฟล์ Excel แล้ววางแทนเนื้อหาในแท็กนี้
